# はじめに

PeerJS を使って、**ブラウザ同士を直接つないで**いっしょに絵を描くツールを、少しずつ組み立てていくハンズオンです。
自分の PC で描いた線が、となりの人のスマホにその場で現れる——そういうものを作ります。

サーバーは書きません。書くのは HTML と CSS と JavaScript だけです。

## この教材の構成

**章（section）** と **節（lecture）** の 2 階層で進めます。章はテーマのまとまり、節は「1 つの動く状態」です。

| 章                                                                      | 種別 | 内容                                                                   |
| ----------------------------------------------------------------------- | ---- | ---------------------------------------------------------------------- |
| [01. 準備](./01-introduction/01-what-we-build/LECTURE.md)               | 準備 | 完成版を触る・エディタ・Netlify Drop                                   |
| [02. 簡単なリアルタイム通信](./02-connect/01-light/LECTURE.md)          | 実装 | ライトを作る → 2 つに増やす → つないで相手の色を変える → 公開          |
| [03. リアルタイム通信の仕組み](./03-how-it-works/01-compare/LECTURE.md) | 解説 | 4 つの通信のやり方・WebRTC は何をする技術か・シグナリングと 3 つの経路 |
| [04. お絵描きアプリを作る](./04-drawing/01-canvas/LECTURE.md)           | 実装 | スタンプ → つなぐ → 線・色・けしごむ・ぜんぶ消すを 1 つずつ足す        |
| [05. アプリの設計](./05-design/01-requirements/LECTURE.md)              | 設計 | 要件をまとめる → ルールを決める → AI と作ってリリースする              |
| [06. 付録](./06-extra/01-cursor/LECTURE.md)                             | 発展 | 相手のカーソル・色塗りバトル                                           |

03 章はコードを書かない解説の章で、02 章で動かしたものの裏側を確かめます。
05 章は手を動かしたあとに読む章です。作れるようになったあと、自分でアプリを作るときの流れを、実際に App Store に出したパズルゲームでたどります。コードは出てきません。

06 章は本編のあとの読みもので、**答えが最初から書いてあります**。
カーソルは 04 章の完成コードに 1 つだけ足したもの、色塗りバトルは同じ仕組みで作った別のアプリです。
どちらも独立しているので、好きなものだけ拾えます。

## 進め方

- **基本はコードを自分で組み立てます。** 各節は前の節のコードに差分を足していく形で進みます。
- **追いつけなくなっても大丈夫。** 各節の末尾に「完成例」パネル（簡易エディタ UI）があり、
  左でファイルを選び、右でコードを確認できます。ZIP でダウンロードして続きから始められます。
- **「前の節との差分」に切り替えられます。** 完成例パネルの上のボタンで、その節で増えた行（`+`）と
  消えた行（`-`）だけを色付きで見られます。隣の「全画面」を押すと画面いっぱいに広がります
  （`Esc` で戻ります）。
- **完成例の `<title>` は節ごとに違います。** ブラウザのタブで見分けやすいように、節の名前にしてあるだけです。
  手元のファイルで書き換えなくても動きます。
- **2 台で動かす節があります。** 02 章の最後で Netlify に公開したあとは、
  スマホや 2 台目の PC でも同じ URL を開いて試してください。

## 各節の完成コードの置き場所

各節の完成コードは、その節のフォルダの `example/` に入っています（`sections/<章>/<節>/example/`）。
ダウンロードした ZIP を展開したものと同じ中身です。ZIP のルートは常に `app/` なので、
前の `app/` に上書き展開すればそのまま育てていけます。

## 動かし方（共通）

`app/index.html` をブラウザで開くだけで動きます。
ただし 2 台で試すときは、Netlify に公開した **https:// の URL** を使ってください
（`file://` のままでは相手の端末から開けません）。

PeerJS 本体は CDN（cdnjs）から読み込むため、インストールは不要です。
