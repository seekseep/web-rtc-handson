# はじめに

PeerJS を使って、**ブラウザ同士を直接つないで**いっしょに絵を描くツールを、少しずつ組み立てていくハンズオンです。
自分の PC で描いた線が、となりの人のスマホにその場で現れる——そういうものを作ります。

サーバーは書きません。書くのは HTML と CSS と JavaScript だけです。

## この教材の構成

**章（section）** と **節（lecture）** の 2 階層で進めます。章はテーマのまとまり、節は「1 つの動く状態」です。

| 章                                                                      | 種別 | 内容                                                                   |
| ----------------------------------------------------------------------- | ---- | ---------------------------------------------------------------------- |
| [01. 準備](./01-introduction/01-what-we-build/LECTURE.md)               | 準備 | 完成版を触る・エディタ・Netlify Drop                                   |
| [02. アプリの設計](./02-design/01-background/LECTURE.md)                | 設計 | 勉強会が生まれた背景・実現方法の調査・何をどの順で作るか               |
| [03. 簡単なリアルタイム通信](./03-connect/01-light/LECTURE.md)          | 実装 | ライトを作る → 2 つに増やす → つないで相手の色を変える → 公開          |
| [04. リアルタイム通信の仕組み](./04-how-it-works/01-compare/LECTURE.md) | 解説 | 4 つの通信のやり方・WebRTC は何をする技術か・シグナリングと 3 つの経路 |
| [05. お絵描きアプリを作る](./05-drawing/01-canvas/LECTURE.md)           | 実装 | スタンプ → つなぐ → 線・色・けしごむ・ぜんぶ消すを 1 つずつ足す        |
| [06. 付録](./06-extra/01-cursor/LECTURE.md)                             | 発展 | 相手のカーソル・色塗りバトル・NAT のしくみ                             |

02 章は手を動かす前に、この勉強会がどうやって生まれたのかをたどりながら、「何を作るか・どう実現するか・どの順で作るか」を決める章です。コードは出てきません。
04 章はコードを書かない解説の章で、03 章で動かしたものの裏側を確かめます。

06 章は本編のあとの読みもので、**答えが最初から書いてあります**。
カーソルは 05 章の完成コードに 1 つだけ足したもの、色塗りバトルは同じ仕組みで作った別のアプリ、
NAT はコードの出てこない解説です。どれも独立しているので、好きなものだけ拾えます。

## 進め方

- **基本はコードを自分で組み立てます。** 各節は前の節のコードに差分を足していく形で進みます。
- **追いつけなくなっても大丈夫。** 各節の末尾に「完成例」パネル（簡易エディタ UI）があり、
  左でファイルを選び、右でコードを確認できます。ZIP でダウンロードして続きから始められます。
- **2 台で動かす節があります。** 03 章の最後で Netlify に公開したあとは、
  スマホや 2 台目の PC でも同じ URL を開いて試してください。

## 各節の完成コードの置き場所

各節の完成コードは、その節のフォルダの `example/` に入っています（`sections/<章>/<節>/example/`）。
ダウンロードした ZIP を展開したものと同じ中身です。ZIP のルートは常に `app/` なので、
前の `app/` に上書き展開すればそのまま育てていけます。

## 動かし方（共通）

`app/index.html` をブラウザで開くだけで動きます。
ただし 2 台で試すときは、Netlify に公開した **https:// の URL** を使ってください
（`file://` のままでは相手の端末から開けません）。

PeerJS 本体は CDN（cdnjs）から読み込むため、インストールは不要です。
