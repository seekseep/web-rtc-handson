# 04 Netlify のアカウントを作る

![Netlify のアカウントを作る](./images/00-thumbnail.svg)

作ったものを **2 台の端末で動かす**ためには、インターネット上の住所（URL）が要ります。
`file://` も `http://localhost` も、自分の端末の中だけの住所なので、
となりのスマホからは開けないからです。

そこで **Netlify** を使います。フォルダをブラウザにドラッグ&ドロップするだけで、
`https://....netlify.app` という URL がその場でもらえます。
ターミナルも Git も使いません。

## アカウントを作る

1. https://app.netlify.com/signup を開きます
2. GitHub / GitLab / Bitbucket / Email のどれかでサインアップします。
   **GitHub アカウントを持っているならそれが一番早い**です
3. チーム名などを聞かれたら、そのまま進めて構いません

無料プランで足ります。クレジットカードの登録も要りません。

:::notice
アカウントを作らなくても公開はできます。ただしその場合、上げたものは
自分のものとして残らず、あとから一覧で探せません。
ログインしておくと、公開したものがアカウントに残って、
あとから開き直したり消したりできます。
:::

## 公開のしかた（この節ではまだやりません）

実際に公開するのは [03 章の最後](../../03-connect/04-deploy/LECTURE.md) です。
どんな操作になるかだけ、先に見ておきます。

**やることは 1 つだけです。**

1. https://app.netlify.com/drop を開きます
2. 点線で囲まれた四角（ドロップゾーン）に、`app` フォルダを**まるごとドラッグ&ドロップ**します
3. 数秒待つと `https://<でたらめな名前>.netlify.app` が発行され、そのまま開けます

![app フォルダをブラウザのドロップゾーンに落とすと、URL が発行される](./images/01-drop.svg)

_図: 落とすのはフォルダそのもの。中の `index.html` を選ぶのではない。_

:::warning
落とすのは `app` フォルダ**そのもの**です。`index.html` が URL の直下に来る必要があります。
`app` の親フォルダを落とすと、`https://....netlify.app/app/` のように 1 階層深い URL になります。
:::

## 直したら、もう一度落とすだけ

コードを直したら、また同じページ（https://app.netlify.com/drop）にフォルダを落とします。
手順は 1 回目とまったく同じです。

**そのかわり、毎回あたらしい URL になります。** 落とすたびに別のサイトが作られるからです。
相手に URL を伝えていたら、伝え直すことになります。

同じ URL のまま中身だけ差し替える方法もあるのですが、ダッシュボードを開いて
プロジェクトを探して…と手順が増えます。このハンズオンでは
**「落とす → 新しい URL が出る → それを使う」だけ**で通します。覚えることが 1 つで済むほうが速いからです。

:::notice
URL は毎回でたらめな名前（`curious-otter-3f1a2b` のような）になります。
スマホで手入力するのは大変なので、**自分あてにメッセージアプリで送る**のが一番早いです。
:::

## 公開したものは誰でも見られます

Netlify で公開した URL は、知っている人なら誰でも開けます。
このハンズオンで作るものに個人情報は入りませんが、
**あいことばを知られると、他人が同じ「へや」に入れる**ことは覚えておいてください。
